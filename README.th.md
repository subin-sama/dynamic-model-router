# Dynamic Model Router

[English](README.md) · [MIT License](LICENSE)

สกิลเลือก **model + reasoning effort ให้เหมาะกับงานแต่ละช่วง** สำหรับ Codex, Claude Code, Gemini CLI และ agent ที่มีตัวควบคุม API อยู่แล้ว ใช้เกณฑ์กลางร่วมกัน แต่ตั้งค่าผ่านกลไกจริงของแต่ละระบบ

งานง่ายใช้คู่ที่ตอบสนองไวพอ งานทั่วไปใช้ระดับสมดุล งานซับซ้อนเพิ่มความสามารถหรือ effort ตามหลักฐาน และลดลงเมื่อส่วนที่ยากจบแล้ว สกิลไม่ผูกกับชื่อรุ่นตายตัว จึงใช้กับโมเดลที่บัญชีของผู้ติดตั้งเข้าถึงได้

## เริ่มใช้

แตก ZIP แล้ววางโฟลเดอร์ `dynamic-model-router` ทั้งโฟลเดอร์ในตำแหน่งของแพลตฟอร์ม เปิดหรือโหลดรายการสกิลใหม่หากแอปยังไม่แสดงสกิล

| แพลตฟอร์ม | ติดตั้งส่วนตัว | ติดตั้งเฉพาะโปรเจกต์ | เรียกใช้ |
| --- | --- | --- | --- |
| Codex | `~/.agents/skills/dynamic-model-router/` | `.agents/skills/dynamic-model-router/` | `$dynamic-model-router` |
| Claude Code | `~/.claude/skills/dynamic-model-router/` | `.claude/skills/dynamic-model-router/` | `/dynamic-model-router` |
| Gemini CLI | `~/.gemini/skills/dynamic-model-router/` หรือ `~/.agents/skills/dynamic-model-router/` | `.gemini/skills/dynamic-model-router/` หรือ `.agents/skills/dynamic-model-router/` | ขอให้ใช้สกิลชื่อ `dynamic-model-router` ผ่านการเปิดใช้สกิลของโฮสต์ |
| API agent | โหลด `SKILL.md` เป็นคำสั่งของ agent และให้ตัวควบคุมเดิมส่ง model/ค่าการคิดจริง | ขึ้นกับระบบ | ขึ้นกับตัวควบคุม |

ติดตั้งเพียงหนึ่งตำแหน่งต่อขอบเขต เพื่อไม่ให้มีชื่อสกิลซ้ำ บาง Codex รุ่นมีเส้นทางสกิลใน Codex home เพิ่มเติม ให้ยึดตำแหน่งที่ client นั้นค้นพบจริง

ตัวอย่างใน Codex:

```text
$dynamic-model-router ช่วยแก้บั๊กนี้ เลือก model และ effort ตามงานแต่ละช่วงเอง
เน้นความถูกต้อง แต่ไม่เพิ่มระดับถ้าไม่มีเหตุผล
```

ตัวอย่างใน Claude Code:

```text
/dynamic-model-router ตรวจปัญหานี้และแก้ให้ครบ เลือกโมเดลกับระดับการคิดที่เหมาะสมเอง
```

บอกความต้องการเพิ่มได้ เช่น "เน้นตอบไว", "ใช้เฉพาะโมเดล X", "effort ไม่เกิน medium" หรือ "อนุญาตให้เลือก model แต่คง effort ที่ตั้งไว้" สกิลต้องเคารพค่าที่ล็อกและตรวจว่าระบบรองรับจริง

## อัตโนมัติได้แค่ไหน

สกิล **เลือกแนวทางอัตโนมัติหลังเปิดใช้** และ **เปลี่ยนค่าจริงได้เมื่อโฮสต์มีเครื่องมือที่อนุญาต** การติดตั้งไม่ได้ทำให้สกิลทำงานทุกข้อความเสมอไป

สำหรับ **agent แม่ของ Codex** มีตัวเปิดต้นแบบเพิ่มแล้ว: [คู่มือ Codex Parent Router](references/codex-parent-router.md) ตัวควบคุมให้ parent เลือกคู่ค่าก่อนทำงาน แล้วเปลี่ยนค่าระหว่างเทิร์นบนบทสนทนาเดิม ทดสอบจริงเพิ่ม–ลดระดับแล้ว: `gpt-6-luna/low → gpt-6.1-sol/high → gpt-6-luna/low` พร้อมรักษาประวัติสนทนา ตัวต้นแบบยังเป็น client แยกสำหรับอ่านข้อความและตอบ ไม่ได้เชื่อมเข้าแชต desktop ปัจจุบันจากการติดตั้งสกิลอย่างเดียว

| ระบบ | วิธีทำงาน |
| --- | --- |
| Codex | เลือกค่าผ่าน subagent หรือการเริ่ม run ที่รองรับและได้รับอนุญาต หากแชตนี้ไม่มีสิทธิ์เปลี่ยนค่า จะรายงานคำแนะนำและทำงานต่อด้วยค่าปัจจุบัน |
| Claude Code | ใช้เครื่องมือ Agent/โปรไฟล์ที่รองรับ รุ่นปัจจุบันยังมี metadata `model` และ `effort` สำหรับสกิล แต่ metadata เป็นค่าคงที่ สกิลกลางนี้ไม่ใส่ไว้เพื่อไม่ล็อกทุกงานเป็นคู่เดียว |
| Gemini CLI | ใช้ Auto ของระบบเมื่อเหมาะสม เลือกค่าการคิดผ่านการตั้งค่าที่ระบบรองรับจริง ไม่สร้างพารามิเตอร์ `effort` ขึ้นเอง |
| API agent | ตัวควบคุมต้องนำผลการเลือกไปส่งใน request จริง การมีไฟล์สกิลอย่างเดียวไม่สร้างตัวควบคุม API ให้ |

ถ้าระบบอนุญาตเพียงการสืบทอดค่าจาก agent แม่ สกิลจะไม่หลบข้อจำกัดด้วย shell หรือแก้ config ถาวร และจะไม่บอกว่าเปลี่ยนโมเดลแล้วโดยไม่มีหลักฐาน สกิลไม่ได้ย้ายบทสนทนาไปผู้ให้บริการอื่นเอง

ถ้าต้องการให้โปรเจกต์ใช้เป็นค่าเริ่มต้น ให้เพิ่มข้อความต่อไปนี้ในไฟล์คำสั่งของโปรเจกต์เอง เช่น `AGENTS.md`, `CLAUDE.md` หรือ `GEMINI.md` ตามแพลตฟอร์ม:

สำหรับ Codex หากต้องการให้ใช้ทุกโปรเจกต์ ให้เพิ่มใน `~/.codex/AGENTS.md` โดยเก็บคำสั่งเดิมไว้ด้วย หากใช้เฉพาะโปรเจกต์ ให้เพิ่มใน `AGENTS.md` ของโปรเจกต์นั้น

```text
Use the installed dynamic-model-router skill for every task.
Reassess model and native reasoning settings at meaningful phase boundaries.
Apply selections only through controls this host exposes and permits.
Preserve explicit user model and effort choices.
```

ข้อความนี้เป็นการเปิดใช้นโยบายของสกิล ไม่เพิ่มสิทธิ์ในการเปลี่ยนค่าที่โฮสต์ไม่อนุญาต แพ็กนี้ไม่แก้ไฟล์คำสั่งหรือค่าตั้งต้นทั่วเครื่องให้เอง

ถ้าต้องการให้ **agent แม่เลือกและเปลี่ยนค่าทุกงานที่ป้อน** ให้เปิด `python3 scripts/codex_parent_router.py` แล้วพิมพ์งานต่อเนื่องในตัวควบคุมนั้นได้เลย ทุกงานจะผ่านการเลือกค่าก่อนทำงาน ตัวควบคุมยังไม่ได้ดักข้อความจากแชต desktop เดิมอัตโนมัติ

## ไฟล์ในแพ็ก

- `SKILL.md` — นโยบายกลาง ภาษาอังกฤษเพื่อใช้ข้ามแพลตฟอร์ม
- `references/hosts.md` — วิธีใช้และขอบเขตของแต่ละโฮสต์ พร้อมลิงก์เอกสารทางการ
- `agents/openai.yaml` — ข้อมูลแสดงผลและอนุญาตให้ Codex พิจารณาเรียกใช้โดยอัตโนมัติ
- `scripts/inspect_models.py` — ตัวช่วยอ่านแคชโมเดลของ Codex แบบออฟไลน์ ใช้ Python 3.9 ขึ้นไป ไม่ใช้ไลบรารีเพิ่ม
- `scripts/codex_parent_router.py` และ `scripts/codex_rpc.py` — ตัวเปิด Codex สำหรับเลือก model/effort ของ parent ระหว่างเทิร์น รองรับงานข้อความแบบอ่านอย่างเดียว
- `tests/test_inspect_models.py` — ชุดทดสอบตัวช่วยแบบออฟไลน์
- `tests/test_codex_rpc.py` และ `tests/test_parent_router.py` — ชุดทดสอบ transport, ลำดับเทิร์น, ค่าที่ล็อก และสถานะการยืนยัน runtime

ตัวช่วย Codex ใช้ตรวจรายการโมเดลและคู่ค่าที่แคชระบุไว้ ไม่ได้จัดอันดับโมเดลหรือเปลี่ยน runtime เอง:

```bash
python3 scripts/inspect_models.py
python3 scripts/inspect_models.py --model MODEL_ID --effort LEVEL
python3 -m unittest discover -s tests -v
```

รันจากโฟลเดอร์สกิล หรือระบุ path ของสคริปต์ให้ครบ ไม่มี API key บัญชีผู้ใช้ หรือข้อมูลแคชส่วนตัวอยู่ในแพ็ก สถานะการตรวจจริงและข้อจำกัดการทดสอบอยู่ใน `VALIDATION.md` ที่แนบกับชุดแจกจ่าย

รายละเอียดของโฮสต์อ้างอิงเอกสารทางการ ณ 2 พฤศจิกายน 2026 ควรตรวจรุ่นและเครื่องมือที่เครื่องปลายทางมีจริงก่อนอ้างว่าเปลี่ยนค่าได้: [Codex](https://learn.chatgpt.com/docs/build-skills), [Claude Code](https://code.claude.com/docs/en/skills), [Gemini CLI](https://geminicli.com/docs/cli/skills/).
